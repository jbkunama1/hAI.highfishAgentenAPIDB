# highfishAPIDB
Moderne und responsive HighFish API DB WebApp mit Dark-Theme. 🐟 Features: Passwortgeschützt (localStorage-basiert), API-Verwaltung (hinzufügen/bearbeiten/löschen), JSON-Export, Suchfunktion, API-Key-Maskierung mit Show/Hide, Copy-to-Clipboard, Mobile-optimiert. Daten speichern lokal im Browser. Passwort: highfish123 (änderbar im Code).
